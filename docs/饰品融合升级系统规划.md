# 饰品融合升级系统

## 概述

**tcc_slot** 槽位中 **COMMON / UNCOMMON / RARE / EPIC** 稀有度的饰品可通过消耗 **内融核心（CoreFusion）** 逐级升级，提升属性效果。

- 等级从 **0 级**起算（未升级即 Lv.0），满级 = 各稀有度封顶等级
- **RIFT** 稀有度、**tcc_3rd** 和 **tcc_tdk** 槽位不参与升级

---

## 一、核心材料

### 内融核心（CoreFusion）

| 属性 | 值 |
|------|------|
| 注册名 | `tcc:core_fusion` |
| 堆叠上限 | 64 |
| 获取 | 融合容器分解饰品、敌人掉落、战利品 |

### 融合容器（Fusion Vessel）

| 属性 | 值 |
|------|------|
| 注册名 | `tcc:fusion_vessel` |
| 堆叠上限 | 1 |
| NBT | `tcc_fusion_count: int`，上限 **655,200**（Config 可调） |
| 交互 | 手持右键空格 → 取出 64 个 CoreFusion；右键 CoreFusion 格 → 存入；右键饰品格 → 分解为 CoreFusion 存入 |

**分解产出公式**：

```
  COMMON:   (10 ÷ 3) × 等级 + 5
  UNCOMMON: 7.5 × 等级 + 10
  RARE:     12.5 × 等级 + 15
  EPIC:     (1 + 等级) × 20
```

| 稀有度 | 0 级产出 | 满级产出 | 满级升级总消耗 | 回收占比 |
|-------|---------|---------|-------------|---------|
| COMMON | **5** | **21** | 310 | 6.8% |
| UNCOMMON | **10** | **70** | 5,100 | 1.4% |
| RARE | **15** | **140** | 30,690 | 0.5% |
| EPIC | **20** | **260** | 163,800 | 0.2% |

## 四、属性增长方式

### 1. 反向计算（属性修饰符类饰品）

Config 配置**满级值**，反向推导各等级实际值：

```
实际值 = 满级值 × (1 + 等级 × C) / (1 + 最大等级 × C)
```

- Lv.0：`满级值 / (1 + 最大等级 × C)` ← 基础值
- Lv.MAX：`满级值` ← 与 Config 一致

### 2. 正向计算（Buff/Effect 类饰品）

Config 配置**基础值**（Lv.0 时效果），按等级正向增长：

```
实际值 = 基础值 × (1 + 等级 × C)
```

- Lv.0：`基础值` ← 与 Config 一致
- Lv.MAX：`基础值 × (1 + 最大等级 × C)` ← 受 C 影响

### 特殊处理

**异况增伤饰品**：采用反向计算，Config 存满级值，`onLivingHurt()` 中对伤害乘算。

**Buff 触发类饰品**：饰品等级直接作为 Buff amplifier，Minecraft 自然缩放。镀层饰品叠加逻辑：已有 Buff 时 `新 amplifier = 原 amplifier + 饰品等级`。

## 五、升级方式

通过**合成台**进行逐级升级（无固定形状，2×2 即可）：

- **输入**：饰品（当前等级 Lv.N）+ 融合容器（内含 ≥ 升级所需 CoreFusion）
- **输出**：饰品（Lv.N+1）+ 返还融合容器（扣除对应消耗）

等级信息存储在饰品 NBT `tcc_fusion_level` 中。

## 六、Config 配置

### 原有饰品属性配置项

- **属性修饰符类（反向）**：配置值为**满级值**
- **Buff/Effect 类（正向）**：配置值为**基础值（Lv.0）**

### 新增融合升级配置项

```toml
[fusion_upgrade]
growthCoefficient = 0.6       # 增长系数 C
ebc_common = 10                # COMMON 基础消耗
ebc_uncommon = 20
ebc_rare = 30
ebc_epic = 40
maxLevel_common = 5            # COMMON 封顶等级
maxLevel_uncommon = 8
maxLevel_rare = 10
maxLevel_epic = 12
fusionVesselCapacity = 655200  # 融合容器容量上限
```
