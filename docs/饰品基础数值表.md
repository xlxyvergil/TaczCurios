# 饰品基础数值表

> 基于融合升级系统，统一使用以下公式确定各等级的属性值：
>
> **当前值 = 基础值 × (1 + (当前等级 - 1) × C)**
>
> C = 增长系数，默认 **0.8**
>
> 满级值 = 基础值 × (1 + (最大等级 - 1) × C)
> 基础值 = Config 中配置的值（即 1 级时的效果值）

## 说明

1. 以上基础值为 **1 级**时的效果值
2. 各等级效果按 **当前值 = 基础值 × (1 + (等级 - 1) × C)** 计算，C 默认 0.8
3. 所有数值最终可配置化，本表为默认值
4. 百分比值取整显示，实际计算使用精确值
5. 异况增伤类饰品的增幅按每负面效果种数计算
6. Buff 触发类饰品等级直接对应 Buff 等级，Minecraft 自然处理效果缩放
