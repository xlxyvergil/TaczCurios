# 饰品基础数值表

> 基于融合升级系统，统一使用以下公式确定各等级的属性值：
>
> **当前值 = 基础值 × (1 + 当前等级 × 0.8)**
>
> 满级值 = Config 中现有数值（即满级后的最终效果值）
> 基础值 = 满级值 / (1 + 最大等级 × 0.8)

## 验证示例

以膛线（RARE）为例验证公式：
```
满级值 = 基础值 × (1 + 最大等级 × 0.8)
1.65 = 0.183 × (1 + 10 × 0.8)
1.65 = 0.183 × 9.0
1.65 ≈ 1.647 ✅
```

以黄蜂蜇刺（RARE）为例验证：
```
2.2 = 0.244 × 9.0
2.2 ≈ 2.196 ✅
```

---

## 说明

1. 以上基础值为 **0 级**时的效果值
2. 各等级效果按 **当前值 = 基础值 × (1 + 等级 × 0.8)** 计算
3. 负面属性（伤害降低/射速降低/不精准等）与正面属性**使用相同增长率**
4. 所有数值最终可配置化，本表为默认值
5. 异况增伤类饰品的增幅按每负面效果种数计算
6. Buff 触发类饰品仅"基础/每级增益值"参与升级，持续时间和最大层数不变
